# Overview
This repository contains the bioinformatics workflows used in the eWHALE project across project partners to analyze metabarcoding data produced by high-throughput sequencing of various target regions (12S, 16S, COI, 18S).

# Data Availability
Raw sequence data that were generated from samples collected in the Azores in 2024 are archived on NCBI under accession PRJNA1522437. 

Sequence data for samples collected in other regions will be uploaded within the next six months.
